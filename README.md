# Mahāsatipaṭṭhāna Matrix

Махасатипаттхана-сутта (Дигха-никая 22, DN 22) в виде схем без повторов, по таблицам Шри Беднатха, ачарьи Випассаны из Непала. Все 11 страниц брошюры. Каждая строка сутты кликабельна: открывает аудиопояснение и перевод на выбранном языке (английский или русский). В матрицах нажатие на ячейку подставляет её термин в скобки [ ].

*Mahāsatipaṭṭhāna Sutta (DN 22) as tables without repetitions, all 11 pages of the brochure. Every line opens its audio explanation and a translation into English or Russian.*

Сайт: https://cobacoder.github.io/satipatthana/ (страница открывается по ссылке вида `#p5`).

Пока текст проверяется, на сайте открыта только страница 1. Какие страницы показывать, задаёт `docs/js/config.js`; все 11 страниц открываются по ссылке с `?all`: https://cobacoder.github.io/satipatthana/?all

## Что где лежит

- `tools/encrypt-audio-links.mjs` — шифрует адреса записей (и адрес таблицы правок) для сайта.
- `tools/review-sheet.gs` — скрипт Google-таблицы, куда режим проверки сохраняет правки.
- `tools/stamp-version.mjs` — ставит номер версии в ссылки на скрипты, см. «Как выпускать».
- `docs/` — сам сайт, его публикует GitHub Pages (ветка `main`, папка `/docs`).
  - `index.html` — каркас страницы и стили.
  - `js/pages/p01.js` … `p11.js` — содержание страниц: текст на пали, переводы, пояснения на хинди и вид схем.
  - `js/helpers.js` — общие части: рефрен «iti ajjhattaṃ vā…», матрица 10 × 6.
  - `js/app.js` — транслитерация, отрисовка схем, плеер, переключение страниц.
  - `js/audio.js` — таймкоды аудио; `js/audio-auto.js` — автоматическая разметка, к которой можно вернуться; `js/audio-lock.js` — зашифрованные адреса записей.
  - `js/review.js` — режим проверки таймкодов (`?review`).
  - `js/config.js` — какие страницы показаны на сайте.
  - `scans/` — сканы страниц брошюры для сверки.

Рабочие материалы (исходный docx, отчёты, промты, исходные аудиозаписи) в репозиторий не попадают, см. `.gitignore`.

## Как устроен текст

- Источник для каждой строки — пали на деванагари (`d`). Латиница (IAST и без диакритики) и кириллица (упрощённая и с диакритикой) получаются из него автоматически.
- Пояснения на хинди и маратхи хранят ещё и ручную транслитерацию по ISO 15919 (`ia`).
- У каждой кликабельной строки постоянный номер: `1.06` — страница 1, строка 6. Ячейки матриц: `6.n.3.5` — матрица `6.n`, строка 3, столбец 5. По этим номерам привязывается аудио.
- Текст на пали сверен с изданием Чаттха Сангаяна (Дигха-никая 22); опечатки брошюры исправлены.

## Аудио

Пояснения — беседы с курса Сатипаттханы, их сайт проигрывает прямо с discourses.dhamma.org (английские и русские, по 9 записей).

- Адреса записей открыто не публикуются. Они лежат в `private/dhamma-recordings.json` (вне git), а на сайт попадают зашифрованными в `docs/js/audio-lock.js`. При первом нажатии на строку с аудио сайт просит логин и пароль для старых студентов, расшифровывает адреса и запоминает их в этом браузере.
- Перешифровать список (например, если сменится пароль или адреса):
  `AUDIO_LOGIN=… AUDIO_PASSWORD=… node tools/encrypt-audio-links.mjs`
- `docs/js/audio.js` — таймкоды строк отдельно для каждого языка: `CUES.en['1.04'] = ['day2', '32:35.7', '32:50.8']`, или несколько кусков подряд — сначала чтение пали, потом объяснение, возможно из разных дней: `CUES.en['1.12'] = [['day2', …], ['day3', …]]`. Дни: `day1` … `day6`, `day7-qa1`, `day8-qa2`, `day9-closing`. Язык записи следует за переключателем EN / RU. Строка `'0'` — название сутты.
- Таймкоды размечены по расшифровкам бесед; `docs/js/audio-auto.js` хранит эту автоматическую разметку без правок.

Пока у строки нет таймкода на выбранном языке, плеер пишет «Для этой строки аудио пока нет».

## Проверка таймкодов

https://cobacoder.github.io/satipatthana/?review — режим для проверяющих: у каждой строки карточка с кусками фрагмента, прослушиванием начала, конца и куска целиком, правкой границ, состоянием («верно», «нужна правка»…) и комментарием. Каждое сохранение — новая строка в общей Google-таблице (адрес и ключ зашифрованы вместе с адресами записей), история правок остаётся, любую строку можно вернуть к автоматической разметке. Одобренные правки переносятся в `docs/js/audio.js`.

## Как выпускать

Перед каждым коммитом: `node tools/stamp-version.mjs`. Он ставит в ссылки на скрипты номер версии (хеш их содержимого), и после выпуска браузер сразу берёт новые файлы: без него GitHub Pages разрешает держать старые до 10 минут.
