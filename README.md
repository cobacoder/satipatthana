# Mahāsatipaṭṭhāna Matrix

Махасатипаттхана-сутта (DN 22) в виде схем без повторов, по таблицам Шри Беднатха, ачарьи Випассаны из Непала. Каждая строка сутты кликабельна: открывает аудиопояснение и перевод на английский и русский.

*Mahāsatipaṭṭhāna Sutta (DN 22) as tables without repetitions. Every line opens its audio explanation and an English and Russian translation.*

## Что где лежит

- `docs/` — сам сайт, его публикует GitHub Pages (ветка `main`, папка `/docs`).
  - `index.html` — страница: схемы, переключатели письменности, плеер.
  - `scans/` — сканы страниц брошюры для сверки.
  - `audio/` — аудиозаписи (появятся позже).

Рабочие материалы (исходный docx, отчёты, промты) в репозиторий не попадают, см. `.gitignore`.

## Как устроен текст

- Источник для каждой строки — Пали на деванагари в атрибуте `data-dev`. Латиница (IAST и без диакритики) и кириллица (упрощённая и с диакритикой) получаются из него автоматически в скрипте страницы.
- Пояснения на хинди хранят ещё и ручную транслитерацию в `data-iast`.
- У каждой кликабельной строки постоянный номер `data-id` (например, `1.06` — страница 1, строка 6). По нему привязываются перевод и аудио.
- Текст на пали сверен с изданием Чаттха Сангаяна (DN 22); опечатки брошюры исправлены.

## Перевод и аудио

В скрипте `docs/index.html`:

- `TR` — перевод каждой строки: `'1.06': ['English', 'Русский']`.
- `SOURCES` — аудиофайлы: `'talk-1': 'audio/talk-1.mp3'`.
- `CUES` — таймкоды строк: `'1.06': ['talk-1', '12:04.5', '12:41']`.

Пока аудио не привязано, плеер показывает демо-режим с условным временем.
